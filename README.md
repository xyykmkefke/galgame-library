# Galgame 库 · 游玩记录

本地优先的 Galgame 浏览与游玩记录 PWA。内置 Bangumi「galgame」「视觉小说」「乙女向」「百合」「BL」「拔作」等日系 galgame 标签条目，并用 VNDB 补充评分、时长与 1939 部日系扩展作品（含关系补全），用月幕 Galgame 补充中文标题与外链，无账号、无后端。

状态：**v2.20.1**

## 功能

- **全库浏览**：4424 部日系作品（2485 部 Bangumi 主库 + 1939 部 VNDB 日系扩展），按年份、平台、开发商、题材、游玩时长筛选，评分 / 热度 / 发售日 / 名称排序
- **搜索**：多关键词交集、`-词` 排除、拼音首字母、跨源别名（VNDB 英文 / 罗马字标题、月幕原名 / 中文名 / 详情别名）、开发商 / 平台命中、标题高亮、搜索历史；严格无结果时自动忽略空格、标点与全半角差异再搜一次；支持 `开发商:Key`、`平台:Switch`、`年份:2015`、`题材:恋爱`、`评分:>=8` 限定（评分支持 `>=` / `<=` / `>` / `<`，省略运算符按 `>=`），前缀 `-` 表示排除
- **我的游玩**：想玩 / 在玩 / 已通关 / 弃坑（仅四种状态）
- **视图**：网格 / 列表 / 看板；按发售年份、加入年份、状态、系列分组
- **详情**：平台、开发、发行、剧本、原画、音乐、游戏类型、题材、相似推荐；平台、开发商、剧本 / 原画 / 音乐 / 发行逐项可点，点制作人员即筛出该人员参与的全部作品；同前缀作品自动归为系列，详情显示「系列 · N 部」并一键筛选整个系列；Bangumi / VNDB / 月幕三外链
- **系列一览**：更多菜单汇总全部系列与覆盖作品数，支持按名称搜索与「只看我收藏的系列」，点击任一即筛选该系列；已收藏的系列会显示「我的 N · 通关 M」，并额外给出「我收藏的系列」卡；Esc 关闭
- **开发商一览**：汇总 1175 个开发商与覆盖作品数，默认列出 2 部及以上（294 个），面板内可按名称搜索、可切换显示仅 1 部的开发商，点击任一即筛选该开发商全部作品
- **制作人员一览**：按剧本 / 原画 / 音乐 / 发行四个维度汇总人员与作品数，默认列出 2 部及以上，面板内可按名称搜索与切换维度，点击任一即筛选该人员参与的全部作品
- **题材一览**：汇总全部 19 个题材的作品数与覆盖作品，按作品数排序，行内显示「我的 N · 通关 M」，点击任一题材即筛选其全部作品
- **平台一览**：汇总 94 个平台（覆盖 2383 部、1046 部多平台），按作品数排序并显示「我的 N · 通关 M」，点击任一平台即筛选该平台作品
- **我的足迹**：按加入月份分组列出全部收藏，显示状态与日期，顶部汇总收藏总数 / 已通关 / 本月新增，点击任意条目直接打开详情
- **同系列切换**：详情页列出同系列其他作品（按发售日升序，最多 12 部，含日期 / 评分 / 我的状态），点击即切换详情，无需返回列表
- **数据统计**：字段覆盖率、年份按十年分布、平台 / 开发商 / 题材 Top，分布条可点击直接跳筛选；最近浏览；一键复制摘要；新增「我的时长（估算）」按 VNDB 时长汇总收藏总时长、已通关与想玩 + 在玩时长，仅统计已匹配条目
- **时长筛选**：按 VNDB 时长分短篇 ≤10h / 中篇 10–30h / 长篇 >30h 三档，可与题材、平台等条件叠加；未匹配 VNDB 的条目不落入任何档位
- **发现**：摇一部（`R`，只在当前筛选结果内抽取）
- **数据**：JSON / CSV / Markdown 导出，JSON 导入合并
- **云同步**：GitHub Gist 双向合并（可选，Token 仅存本机），删除墓碑、失败退避
- **PWA**：安装引导（Chrome / Edge 原生提示，iOS 给出添加到主屏幕步骤）、离线缓存、新版本刷新提示
- **无障碍**：键盘导航、焦点陷阱、状态播报、44px 触控目标

## 数据

- 主源：Bangumi（bgm.tv），`type=4` 游戏，`tag=galgame` / `视觉小说` / `乙女向` / `百合` / `BL` / `拔作` 按 ID 合并去重；不收 ADV（混入大量非 gal 的冒险 / 解谜游戏），也不收标为欧美的作品
- 扩展源：VNDB 公共 Kana API，只收原始语言为日文（`olang=ja`）、评分 ≥ 60、投票数 ≥ 30 的作品，按热度降序取 1500 部；再以主库 VNDB 映射 + 扩展库为种子批量遍历 `relations`，补同系列 / 同设定 / 前传续作等 439 部，合计 1939 部。全部与主库 VNDB 映射、主库标题、月幕别名去重后独立写入 `data/vndb-extra.js`，运行时并入全库（`ex=1`），详情只提供 VNDB 外链
- 补充源：VNDB 公共 Kana API，按标题归一 + 年份容差保守匹配，只保留高置信结果；当前匹配 1042 条（已尝试 1840 条）
- 补充源：月幕 Galgame 开放 API，同样按标题归一 + 年份容差严格匹配；当前匹配 909 条，其中 577 条有详情别名
- 规模：4424 条（主库 2485 + 扩展 1939；1985-05-31 ~ 2027-03-25）
- 覆盖：日期 98.8%、评分 98.6%、封面 100%、平台 97.7%、开发商 87.2%、题材 62.6%
- 文件：`data/galgames.js`（主库）、`data/vndb.js`（第二数据源）、`data/ymgal.js`（第三数据源）、`data/vndb-extra.js`（日系扩展库），后三者按 Bangumi ID 或独立 ID 段关联

抓取按发售年份分桶（镜像 offset 上限 1000），再用 heat / rank / score 三个排序各取前 1000 条兜底：

```bash
npm run fetch-data          # 增量，已有分桶缓存直接复用
node scripts/fetch-games.mjs --refresh   # 清空缓存重抓
node scripts/fetch-games.mjs --tags=galgame,视觉小说,乙女向   # 指定标签
npm run fetch-vndb          # 补充 VNDB（默认热度前 350 条，增量）
npm run fetch-vndb-extra    # 抓取 VNDB 日系扩展库（默认 1500 条，整包重抓）
npm run fetch-ymgal         # 补充月幕（默认热度前 700 条，增量）
npm run check-data
```

平台在构建期归一：Windows 各版本 / Win 98 → `PC`，PlayStation 各代 → `PS` 系，安卓 → `Android`，浏览器 / 在线网页 → `Web`，并过滤版本号等碎片。开发商名去掉「株式会社」「Co., Ltd.」等后缀。桶缓存保留原始平台串与标签，调整映射后可离线重算。

VNDB 匿名限流约 200 次 / 5 分钟，脚本固定 1.6s 间隔并对 429 退避；匹配结果落 `data/build/vndb-map.json`，重复运行只补未匹配条目。

扩展库脚本按热度降序分页拉取（每页 100 条、间隔 1s），22 页取满 1500 条；再按 50 个 id 一批遍历 2533 个种子的 `relations`（只跟随 seq / preq / set / alt / side 等官方关系，跳过 char / fan），补字段完整的相关作品 439 条。标题 / 别名归一后与主库和月幕去重，输出独立文件，不写主库。

月幕使用官方公开的公共凭据（`client_id=ymgal`，供学习 / 实验），构建期顺序请求、800ms 间隔并对 429 退避，匹配结果落 `data/build/ymgal-map.json`；有匹配的条目再逐条取详情补 `extensionName` 别名（同样 800ms 限速）。也可用环境变量 `YMGAL_CLIENT_ID` / `YMGAL_CLIENT_SECRET` 覆盖。数据非商业用途，本站已在页脚与文档标注月幕 Galgame 来源。
